# UI焼き込み プラグイン 1.0.0

このプラグインは、ゆっくりMovieMaker4（YMM4）のプレビュー上のUIを再現し、選択状態に関わらず常に表示するための拡張機能です。

## -使い方-
プラグインが導入されたら、お好みの図形や映像に映像エフェクト「UI焼き込み」を追加します。

### UI見た目の設定
「ズーム率」「遅延描画」「ドロップシャドウ」「UI色」からお好みの見た目に変更できます。デフォルトではYMM4と同じ見た目に設定されていますが、ズーム率については多少の差が生じることがあります。

### ハンドルの設定
「外枠」「拡大縮小ハンドル」「回転ハンドル」からお好みの見た目に変更できます。デフォルトではYMM4と同じ見た目に設定されています。「外枠」はアイテム外周の破線枠、「拡大縮小ハンドル」は四隅の四角形のハンドル、「回転ハンドル」は辺中央の丸のハンドルで、トグルで表示の有無を変更できます。

### アニメーション軌跡の設定
「軌跡」「矢印」「マーカー」からお好みの見た目に変更できます。デフォルトではYMM4と同じ見た目に設定されています。「軌跡」は点線の移動パス、「矢印」は軌跡区間中央に表示する進行方向の矢印、「マーカー」はキーフレーム位置の大サイズマーカーで、トグルで表示の有無を変更できます。

### スナップガイド
X軸のガイドの設定、Y軸のガイドの設定からお好みの見た目に変更できます。ガイドの座標を決め、軸のトグルをオンにすることで、YMM4と同じ見た目のガイドが表示されます。
